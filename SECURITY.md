# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting feature for this repository instead.

Include the affected version or commit, reproduction steps, potential impact, and any suggested mitigation. Avoid including real investigative locations, case data, credentials, or other sensitive material in the report.

Security reports will be acknowledged and assessed before public disclosure. There is no guaranteed response or remediation timeline.

## Operational data

Range 4-Ren performs calculations and creates exports in the browser. Users remain responsible for handling coordinates, exported GeoJSON, and other investigative data according to their own policies. Do not submit operational data in GitHub issues or test fixtures.
